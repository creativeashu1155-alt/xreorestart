# Work With Aarohi — Website Starter

A responsive, single-file landing page starter created in `index.html`.

## Preview locally

Open `index.html` in a browser. No build step is required.

## Current limitations

- This is a best-effort starter because the reference site could not be retrieved for inspection.
- The contact form is a front-end demo and does not send or store submissions.
- No private backend, database, original assets, or third-party integrations have been copied.

## Deploy

The static page can be hosted by GitHub Pages or any static hosting provider. Configure the host to publish the repository root.
